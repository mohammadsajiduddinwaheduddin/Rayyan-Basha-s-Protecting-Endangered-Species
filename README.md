# Protecting Endangered Species — Wildlife Conservation Portal

Created by **Rayyan Basha Mohammad Sajiduddin Waheduddin** (Grade 7) for the **New Middle East International School — Web Design Competition 2026**.

## Overview

This multi-page web project raises awareness about endangered wildlife, ecosystem protection, and smart conservation technology. It features:

- **Animated Intro & Portal Splash** leading into the main conservation dashboard (`index.html`)
- **Interactive Wildlife Spotlights** covering the Bengal Tiger, African Elephant, and Sea Turtle
- **Conservation Goal Spotlights** focusing on anti-poaching surveillance, habitat restoration, environmental awareness, and conservation technology
- **Pledge Form** allowing visitors to commit to wildlife-friendly actions (`campaign.html` and the campaign modal in `index.html`)


## Project Files

- `index.html` — Main landing page, intro animations, interactive cards, conservation goals, and modal popups
- `campaign.html` — Dedicated wildlife conservation pledge form page
- `tiger.html`, `elephant.html`, `turtle.html` — Individual species spotlight pages
- `goal-protection.html`, `goal-habitats.html`, `goal-awareness.html`, `goal-technology.html` — Individual conservation goal pages


## How to Run Locally

1. Clone or download the repository folder.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, or Safari).
3. An active internet connection is recommended so external Unsplash images load properly.
